# HeiHeiSMT 第二阶段：源码调查与路线判断

## 一、阶段目标

第一阶段已经完成 HeiHeiSMT 0.5.1 发布包的只读静态审计。

第二阶段原计划：

1. 获取 `hbgda/SMT` 源码。
2. 找到与 SMT 0.5.1 对应的 commit / tag。
3. 从源码层面分析：
   - 网络协议
   - Host / Client
   - Game State Sync
   - Mission
   - Objective
   - Checkpoint
   - Save / Progression
4. 判断现有 Mod 是否已经具有任务同步框架。
