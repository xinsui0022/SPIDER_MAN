# 联机 MOD 可移植性审计

2026-10-06，依据本机文件与既有静态审计。核验没有修改原 MOD 或存档，没有输出账户 ID、连接地址或连接名称。后续按用户授权新建了独立离线候选目录与 ZIP，没有安装到任何电脑，也没有向他人发送文件。

## 结论

这份 MOD 的主要运行路径是相对路径，因此可以准备给另一台 Windows x64 电脑使用的安装包；接收方无需采用本机的 D 盘目录或 Windows 用户名。尚未在另一台电脑实测，不能保证任意游戏版本、Steam 环境或网络都可直接运行。

**可移植性不等于剧情可用性。** 用户报告初始化 NG+ 首次进入有任务、再次进入任务消失，说明先前测试档仍存在重载问题。复制到哥哥电脑会保留相同 MOD 行为；复制主机存档也不能证明或实现客机剧情、经验、资源同步。

## 建议候选运行文件

以下结构放在接收方 `Spider-Man.exe` 所在目录。它是保守的候选清单，尚未通过逐项删减实机测试证明为严格最小集合。

```text
游戏目录/
├─ winmm.dll
├─ miniupnpc.dll
├─ discord-rpc.dll
├─ cache
└─ SMT/
   ├─ Multiplayer.json
   ├─ Preferences.json
   ├─ Connections.json        # 使用清空连接列表的配置，不携带原地址
   ├─ Scripts/smt.dll
   ├─ Assets/UI
   └─ UI/
      ├─ Title.gfx
      ├─ SystemOverlay_UIv2.gfx
      ├─ POIs.gfx
      ├─ Overlay.gfx
      └─ HUD.gfx
```

- `SMT-Launcher.exe` 可选。现有文件式启动可继续使用；代理加载器检查 `-mp` 参数，启动时还应以游戏目录作为工作目录。Launcher 已检查的直接启动分支也会把工作目录设为游戏 EXE 所在目录。
- `miniupnpc.dll` 是核心直接导入的依赖。`discord-rpc.dll` 有动态接口调用证据，不能仅因关闭 Presence 配置便认定可删除。
- MOD 的 `cache` 为 6,833 字节，恰为 8 字节头与 273 条各 25 字节记录；字段包含与本机游戏 PE 时间戳相同的值，所有 8 字节位置值均在游戏映像范围内。读取代码按 8/4/8/4/1 字节顺序处理记录，另有写回入口，符合按游戏构建区分的相对偏移缓存。未发现本机用户名、盘符、IP 或 Steam ID 文本，不能把它理解为本机 ASLR 绝对地址表。完整再生成及跨版本兼容尚未实机验证，保留原文件。它与游戏的 `cache.pso` 不是同一文件。
- 原包没有 `SMT/UI/Race.gfx`、`SMT/Assets/MP_Logo.texture`，尽管核心中有对应路径字符串。字符串本身不能证明这些缺失文件是必需文件，不能据此补入来源不明资源。

## 路径及配置

已确认代理使用 `./SMT/Scripts`，核心含 `SMT/Save/`、`SMT/UI/...`、`SMT/Assets` 与 `cache` 相对路径。游戏原资源路径为 `configs/missionorderconfig/...`，由接收方自己的游戏提供。

三份配置内容的结构均没有本机游戏 EXE 的绝对路径字段：

| 配置 | 内容 | 移植处理 |
|---|---|---|
| `Connections.json` | `Connections` 数组内的 `ip`、`name`；`ShowIp` | 应清空旧列表，按新会话重新填地址；本机地址不进入分享包 |
| `Preferences.json` | Discord Presence、加入请求、控制台、ImGui 布尔开关 | 可作为默认配置，接收方可自行设置 |
| `Multiplayer.json` | 犯罪事件、敌人参数、移动、角色缩放、显示参数 | 可作为默认配置；这些开关不证明敌人或任务状态同步已实现 |

可准备的新连接配置结构为：

```json
{
  "Connections": [],
  "ShowIp": false
}
```

候选包采用以上空模板，本次没有改写当前游戏配置，也没有实测空列表首次启动。

未确认存在绑定本机用户名、盘符或固定 Steam 账户的检查；源码缺失，不能把“没有找到”写成已证明没有授权限制。代理里的 PDB 绝对路径属于调试元数据，不能当作安装路径依赖。

## Steam、系统与网络条件

- 核心直接导入 `steam_api64.dll`，并使用 Steam 初始化、运行状态、用户接口、回调、好友与 Lobby 相关接口。接收方应使用自身游戏安装提供的 Steam API 文件，不能把本机的整个游戏根目录或 Steam/第三方账户文件复制过去代替安装。
- 核心依赖 `MSVCP140.dll`、`VCRUNTIME140.dll`、`VCRUNTIME140_1.dll` 与 Windows Universal CRT，属于 x64 Visual C++ 运行库依赖。尚未检查哥哥电脑是否已满足。
- 静态代码实际调用 UPnP 添加映射，端口为 TCP 7637、UDP 7638。此证据说明端口映射逻辑，未证明每种端口承载的具体状态，也不能保证不同路由器、NAT 或防火墙允许连接。本次没有修改防火墙或路由器。
- Discord RPC 是 Presence/加入请求集成，不能把名称中的 RPC 解释为任务同步协议。尚未证明关闭该功能会影响或不影响基本联网。

## 分享包应排除的项目

- 整个 `SMT/Save`、`Save.codex-*`、普通游戏存档、手动存档、`-userprefs.save`、测试 NG+ 和回退备份。哥哥使用自己的槽位；如以后需要指定测试档，应单独明确用途并保护其原档。
- 原 `Connections.json`、`SMT/Logs`、游戏日志、崩溃转储、`序章修复调查` 及全部诊断记录。诊断可能包含电脑路径、会话信息和地址。
- 游戏 EXE、`asset_archive`、`cache.pso`、显卡缓存及原游戏 DLL。哥哥应有自己的游戏安装。
- 本机额外的 `3DMGAME`、`3dm64.dll`、汉化程序、卖家目录、旧报告等。它们不是上述已确认的 MOD 文件清单。

原始 ZIP 自带 23 个存档/备份/偏好文件及一个连接项，直接转发原 ZIP 并不等于无存档、无地址的干净安装包。新候选 ZIP 采用白名单收集，没有携带这些项目。
