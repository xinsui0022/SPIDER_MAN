原版 NG+ 在“创建但尚未开始”和“已经开始序章”之间确实有一组初始化状态变化。**CurrentLevel=-1 本身可以是合法的待开始状态**；它不能单独证明存档损坏。原版创建时同时保留 NewGamePlusNewGame=true、无活动任务、无屋顶 perch；开始后才置 NewGamePlusNewGame=false，并建立 CurrentLevel=0、有效检查点和序章任务。
