# 最终需求与验收

| 需求 | 验收行为 |
| --- | --- |
| 双人联机 | 两台电脑各自控制一个角色，在同一个主机世界活动与战斗 |
| 主机权威场景 | 门、电梯、机关、动画与碰撞、战斗波次、任务触发和通路以主机为准；客机不能门关/仍有碰撞 |
| 同一批敌人 | 身份、生成、位置、状态、血量、死亡、任务计数一致，不能两端分别产生互相矛盾的敌人 |
| 双方攻击生效 | 主客机攻击都交给主机结算，敌人响应两名玩家，死亡与奖励一致 |
| 剧情同步 | 主机触发→召集另一名玩家→双方场景/演员就绪→同段剧情→任一人跳过双方正常收尾→世界终态一致 |
| 普通新档 | 从普通1级新游戏、教程和序章开始；50级NG+测试不替代普通新档 |
| 保存继续 | 主机合作进度保存，双方下次恢复正确任务、门、敌人及检查点，保留个人原档 |
| 奖励升级 | 经验、等级、升级资源按主机结算共享；具体装备/技能个人差异后续细化 |
| 晚加入/重连 | 恢复已开门、已死敌人、当前任务阶段与通路 |

原 SMT/HeiheiSMT 仅为参考；缺少源码不限制自主实现。不能把移动穿门、改任务完成标记、网络消息一致或摘要相同当作世界同步成功。

用户提出的跳过规则是“任一方跳过则双方跳过”，不要求双方投票。没有原生跳过提示的剧情尚没有强制跳过验证；是否兼容强制跳过必须由合法收尾与任务一致性证据决定。

原机的两类门问题要分别跟踪：主机坏档重载卡门；主机已开、客机仍关且碰撞不一致。它们并非已经由 DoorStep 或存档复制解决。
