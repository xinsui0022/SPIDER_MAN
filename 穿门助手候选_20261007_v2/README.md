# 穿门助手 DoorStep 0.1 候选

按角色朝向进行一次短距离传送，帮助绕过不同步的门或薄墙，并提供上一次移动的返回点。当前支持本机已核验的游戏 4.630.0.0 和 SMT 0.5.1。

这是独立附加插件，安装包只包含穿门助手；哥哥需先安装与你相同版本的游戏和 SMT 联机 MOD。两台电脑可以分别安装，分别控制各自角色。保留原有启动参数和联机步骤。

## 安装与操作

1. 从游戏菜单正常退出。将 `安装文件/SMT/Scripts/DoorStep.dll` 和 `DoorStep.ini` 复制进游戏的 `SMT/Scripts`；也可以运行安装脚本并输入包含 `Spider-Man.exe` 的目录。
2. 按原有 `-mp` 方式启动，进入能够控制角色的场景。插件初始化期间会在 `SMT/Scripts/DoorStep.log` 写状态；成功时记录 `READY`。
3. 在游戏窗口中按 **F7** 启用，听到两声提示。先在平地朝空地站稳，按 **F8** 向角色面前移动 **2.5 米**，间隔约一秒再按 **F9** 返回，验证方向及稳定性。**PageUp** 每次上移 **1 米**；**PageDown** 每次下移 **1 米**；上下移动也可以按 F9 返回。移动与返回按键之间建议间隔约一秒；过快的请求可能被忽略。
4. 平地测试成功后，靠近门、面向门按 F8。单声高音表示原生移动已应用；低音表示请求被拒绝或位置没有保持，原因在日志中。按 F7 关闭。

F9 返回上一次移动前的位置：限同一角色和任务状态、120 秒内、距离不超过 12 米。暂停或加载造成本地更新中断、任务阶段变化、离开游戏窗口、关闭功能会清除返回点。每按一次 F8、PageUp 或 PageDown 会更新返回点。

这是短距离移动，碰撞依然正常。门后的场景和剧情触发仍依赖游戏及联机同步；首次测试结果需要分别记录“移动是否成功”“是否拉回”“是否能继续剧情”。敌人伤害、血量及死亡同步尚未验证。

`DoorStep.ini` 的 `StepMeters`（水平距离）和 `VerticalMeters`（上下距离）可设为 0.5～5.0；修改后重启游戏生效。先保留默认值。

## 停用

正常退出游戏，再把 `SMT/Scripts/DoorStep.dll` 改成不以 `.dll` 结尾的名字，或运行停用脚本。插件在游戏进程结束时退出，避免在运行中卸载。

## 验证范围

已完成代码和本地对象的只读核对，以及独立进程中的离线检查。候选初始关闭，只有手动按键后才提交移动请求；对游戏/SMT文件哈希、运行时指令、角色身份和矩阵作检查。原生移动在 Mover 作业结束后的串行提交阶段执行。

**主机游戏内加载、F8 向前移动及 F9 返回已由日志和用户实测确认；PageUp 上移已由日志确认，用户也确认能返回。PageDown 下移、实际穿门、客机效果和剧情推进仍待实测。** 当前候选不包含修复好的剧情、敌人或存档共享协议。
